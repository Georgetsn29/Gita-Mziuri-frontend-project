## About The Project

Aterna is a fully responsive, multi-page frontend project for a modern landscaping and gardening company. This project showcases a clean and elegant design, built with HTML, SCSS, and JavaScript. It incorporates various libraries to create a dynamic, animated, and visually appealing user experience, demonstrating modern web development practices.

## ✨ Key Features

*   **Fully Responsive Design:** Adapts seamlessly to all screen sizes, from mobile phones to desktops.
*   **Multi-Page Layout:** Includes Home, About Us, Blog, FAQ, and Contact pages.
*   **Interactive Hero Slider:** A full-screen Bootstrap carousel on the homepage with custom animations.
*   **Dynamic Animations:** Smooth scroll animations powered by the AOS (Animate On Scroll) library.
*   **Interactive Carousels:** Owl Carousel is used for the client testimonials and gardening tips sections.
*   **Content Filtering:** A filterable gallery to showcase different services and projects.
*   **Modern UI Components:** Includes tabbed content sections, an accordion for the FAQ page, and a contact form with a date picker (Flatpickr).
*   **SCSS Architecture:** Organized and modular styling with variables, mixins, and partials for maintainability.

## 📄 Pages Included

*   **Home:** The main landing page featuring all key sections.
*   **About Us:** Information about the company and team members.
*   **Blog Article:** A sample blog post layout.
*   **FAQ:** A frequently asked questions page with a collapsible accordion.
*   **Contact:** A contact page with a submission form and an embedded location map.

## 🛠️ Technologies Used

*   **HTML5**
*   **SCSS/CSS3**
*   **JavaScript**
*   **Bootstrap 5:** For responsive layout and components.
*   **AOS (Animate On Scroll):** For scroll-triggered animations.
*   **Owl Carousel 2:** For touch-enabled carousels.
*   **jQuery:** Used as a dependency for Owl Carousel.
*   **Flatpickr:** For the date picker in the contact form.
*   **Font Awesome & Bootstrap Icons:** For icons throughout the site.

## 🚀 Getting Started

To run this project locally, follow these simple steps:

1.  Clone the repository:
    ```bash
    git clone https://github.com/georgetsn29/gita-mziuri-frontend-project.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd gita-mziuri-frontend-project
    ```
3.  Open the `index.html` file in your favorite web browser.
